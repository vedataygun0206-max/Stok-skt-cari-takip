# Stok-SKT-Cari-Takip

Sıfırdan geliştirilen kapsamlı market stok, SKT, cari, POS, kasa ve raporlama sistemi.

## İlk sürüm
- Firma / şube
- Kullanıcı / rol
- Ürün kartı
- Barkod
- Depo
- Stok
- Parti / SKT
- Cari
- Audit log altyapısı

## Teknoloji
- Cloudflare Workers
- Cloudflare D1
- Vanilla JS + HTML/CSS (hafif yönetim paneli)
- Modüler REST API

Sonraki modüller: satın alma, mal kabul, POS, kasa, finans, raporlama, e-fatura/e-arşiv ve entegrasyonlar.
